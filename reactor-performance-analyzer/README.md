# Reactor Performance Analyzer

A Python tool for analyzing chemical reactor data and calculating key reactor engineering performance metrics such as conversion, reaction rate, space time, and reactor sizing.

This project is designed to interpret reactor data from simulations or experiments and visualize important relationships used in chemical reaction engineering.

---

# Features

The Reactor Performance Analyzer can:

- Calculate reactant **conversion**
- Compute **reaction rates** from concentration data
- Determine **space time**
- Estimate **reactor volume required for a desired conversion**
- Generate **engineering plots for reactor analysis**
- Create **Levenspiel plots for reactor sizing**

---

# Engineering Concepts Used

This project implements several fundamental reaction engineering equations.

### Conversion

X = (CA0 − CA) / CA0

### Space Time

τ = V / v0

### PFR Design Equation

V = FA0 ∫(dX / −rA)

These equations are commonly used to analyze and design plug flow reactors.

# Generated Plots

The analyzer can generate several plots used in reactor analysis:

- Conversion vs Reactor Volume
- Reaction Rate vs Concentration
- Levenspiel Plot (1/−rA vs Conversion)

These plots help engineers understand reactor efficiency and determine required reactor size.
